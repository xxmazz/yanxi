# 表格、公式与更新研究核对

2026-10-30 新增三个可运行入口，不修改已有 PDF、解析正文或向量。

## 阅读器：表格与编号公式

“沉浸阅读”选择文献和物理页码，在正文侧点击“提取本页表格与编号公式”。首次按需运行本地 pdfplumber，结果按原件 SHA-256、物理页码与提取版本缓存在独立目录。单页子进程超时45秒，字符、图形边与输出大小有上限，失败可重试。

表格由表题、同宽水平线和文字列位置共同限定，保留表头、空字符串、跨列 null、原文及归一化坐标。完整单词跨列时保留整体，避免切碎训练成本等数值。科学计数法仅在原始字形的字号与上移位置均支持时用 `^` 标记指数，例如 `2.3·10^19`；不凭文本中连续数字猜指数。单元格候选与裁剪原图并排，CSV 使用 UTF-8 BOM，处理引号、换行及电子表格公式前缀。

编号公式要求右侧独立括号编号和邻近数学符号，提供原图、文本层转写、坐标及原 PDF 页码入口。原图保留分数、上下标及原版式；转写不是 LaTeX，不承诺重建任意数学表达式。未编号公式可能漏检。

这些是自动候选，复杂多层表头、跨页表格及错误文本层仍需核验；扫描页保留已有 GPU OCR 和原页，不把 OCR 文字拼装成精确表格或公式。

新增接口：

- `GET /api/documents/{id}/pages/{page}/structure`
- `GET /api/documents/{id}/pages/{page}/structure/{item}/image`
- `GET /api/documents/{id}/pages/{page}/structure/{item}/csv`

## 图表：多个系列与雷达图

写作工坊的数据可视化支持首列类别、后续1–6列有限数值，最多30行。柱状图分组，折线图各系列独立绘制；SVG保留图例、原值提示和数据描述。图注逐列计算最大/最小值，不推断显著性、因果或“越大越好”。

雷达图限3–12个非负指标行，所有系列共用从零到全局最大值的刻度，不偷偷按列归一化。用户须保证指标单位与方向可比较；负值仍可使用柱状/折线图。窄屏可在图内横向滚动，页面不溢出。原始CSV随图注导出。

## 图谱：Future Work 与较新摘要核对

构图后在“后续研究线索”输入拟议主题，点击“核对更新研究”。范围与指纹必须对应当前有效原文；核对期间原文变化会拒绝返回旧结果。

系统保留至多4份明确 Future Work 原文，取其中最近的已知发表年份；arXiv按最新提交检索至多8篇候选，仅保留原文最近年份之后首次发表的论文。本地E5按本次主题重排后，最多4篇交由Qwen逐篇概括与主题相关的方法，检查来源编号和数值。无来源通过的概括显示拒答，候选摘要、日期、arXiv地址仍可查看；过期缓存不作为成功核对。可导出包括旧方向原文、较新摘要、时间和模型结果的JSON。

这是有限候选的文献对照入口，不能证明某个方向从未被研究，不能用摘要替代完整相关工作审查。模型也不会把“未检出”改写成“首创”。论文元数据检索联网，所有生成、向量和OCR模型均运行在本地。
