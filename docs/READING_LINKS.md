# 正文引用与参考文献双向导航

2026-10-29，为原页与解析正文阅读模式接入数字制引用跳转。打开已就绪文献，在解析正文中点击 `[13]` 等编号，展示对应书目、同步到物理页并高亮原文；可返回刚才的正文位置，或从书目列表选择其他出现位置。原始 PDF 链接用于回看排版。

## 实现范围

- 从独立 References／Bibliography／参考文献标题读取书目，沿用图谱的附录停止规则，只识别独立行起始的 `[数字]` 条目。
- 正文支持单编号、逗号分组和短范围（例如 `[1, 3–5]`）。编号必须全部在书目中存在；重复书目编号、倒序范围、超过 30 个编号跨度及未知编号不生成链接。
- 跨页书目保存多个原文区间，不重写、翻译或拼造原始书目。每个区间包含物理页码、字符起止和页 SHA-256。
- SQLite 一致快照读取已解析并确认的文献，校验页数和大小上限；前端使用 Unicode 码点定位，先核对摘录与当前正文相同，再显示高亮。
- 导航面板跨页加载期间保留原位置；更换文献时清空。中英翻译模式仍使用原有翻译流程。

当前定位在解析正文中，左侧原页同步到对应页；没有实现直接点击 PDF 图像上的编号，也没有 PDF.js 页内文字覆盖层。后续已补充有限英文作者年份制（见下节）；上标、脚注、复杂分栏、章节独立书目及 OCR 错字仍需进一步处理。数字匹配可能把数学方括号当作候选，须结合原页核对。该功能不调用模型，不需要 GPU 或新增运行依赖。

## 真实验收

| 官方样本                  | 识别书目 | 正文引用组 | 原文坐标与哈希核对 |
| ------------------------- | -------- | ---------- | ------------------ |
| Transformer v7            | 40       | 57         | 97 个区间通过      |
| Transformer v1 官方扫描件 | 28       | 6          | 34 个区间通过      |
| BERT（作者年份制）        | 0        | 0          | 明确不生成数字链接 |

浏览器实测 Transformer 第 2 页 `[13]` → 第 11 页 Hochreiter 与 Schmidhuber 的 LSTM 书目 → 返回第 2 页 `[13]` 并高亮；左侧原页随物理页同步。扫描件计数明显较少，反映已有 OCR 文字质量的限制，不声称完整召回率。

105 项后端测试、5 项前端工具测试和生产构建通过。新增回归覆盖组合／范围编号、跨页、Unicode 坐标、重复编号隔离、缺少 References、作者年份制、指纹变化、未就绪与缺页拒绝及 API 状态码。真实结果见 [验收数据](READING_LINKS_VERIFICATION_20261029.json)。公开报告只保存数量、身份和哈希，不分发论文全文。

```sh
.venv/bin/python scripts/verify_reading_links.py \
  --base-url http://127.0.0.1:18474 \
  --fixture-dir /path/to/科研小助手/pdf \
  --output docs/READING_LINKS_VERIFICATION_20261029.json
```

接口：`GET /api/documents/{id}/reading-links`。文献不存在返回 404，未完成解析／版本确认或页数据不完整返回 409。返回 entries、mentions、文献指纹和识别限制。

本轮用仅监听回环地址的临时 CPU 服务进行验收，完成后停止；生产模型服务保持停止，显存继续释放。代码与构建已同步服务器，下次启动正式服务即可使用。

## 英文作者年份制补充验收

同日继续补充 BERT 等英文论文的作者年份引用：依据可识别的英文作者列表及出版年份分割书目，正文通过首位作者姓氏＋年份匹配，保留 2018a／2018b 后缀；支持 et al.、两作者 and／&、叙述式年份括号和 PDF 行末断词。原文字符坐标经映射保留，界面直接显示作者年份标签，内部定位序号不冒充原文引用编号。

同姓同年对应多条书目时不自动链接；第二作者不属于对应书目时拒绝；遇到无法分割的相邻书目，不将其合并成完整来源。数字引用和作者年份引用采用不同识别路径，作者年份模式不会把正文 [1] 误当作内部书目序号。指纹加入算法版本 reading-links-v2。

BERT 目前识别 50 条可定位书目、74 处正文候选引用，126 个区间的原文坐标与页哈希全部核对。重点抽查首页 Peters et al., 2018a（Deep contextualized word representations）、Radford et al., 2018（Improving language understanding...）、Howard and Ruder, 2018（Universal language model fine-tuning...）的实际书目题名。浏览器验证 Peters／Radford 首页→第11页→返回首页原位置；不声称其余全部候选都经过语义审查。

前一张表的 BERT 0/0 是数字制首次验收的历史结果，保留原始记录。新的数字制及作者年份制结果见 [补充验收数据](AUTHOR_YEAR_VERIFICATION_20261029.json)。Transformer v7 的 40 条书目／57 处引用以及官方扫描件的 28 条书目／6 处引用保持一致。后端共 108 项测试、前端 5 项工具测试及构建通过。

书目识别仍是有界规则。姓名缩写／复杂变音符、倒置作者格式、多个年份共用作者、跨物理页拆开的正文引用、非英语姓名和不同格式可能漏识别；初验中未可靠识别的部分书目保持不可跳转。数字匹配也不等于完整引用语义审查。没有调用云端或本地模型，GPU 保持空闲。
