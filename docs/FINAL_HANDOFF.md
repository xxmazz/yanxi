## 192服务器怎样运行

代码目录为`/data1/yanxi`，日常由用户级systemd管理；四卡分工保持Qwen占0/1、E5占2、OCR占3。现在无任务时服务停止，释放显卡。

```sh
ssh nlp
cd /data1/yanxi
systemctl --user start yanxi
systemctl --user status yanxi --no-pager
# 等待模型加载，再在局域网浏览器打开下方地址。
```

局域网入口为`http://192.168.3.193:18474/`；此现有实例未开启评审账号。启动后确认页面“本地模型已连接”，再运行问答。若等待较久，在服务器执行`tail -n 60 runtime/server.log`核对启动错误。新机器从[完整GPU安装](LOCAL_BACKEND.md)及[独立复现](GPU_REPRODUCTION.md)准备依赖与外置权重。

用完停止：

```sh
systemctl --user stop yanxi
nvidia-smi --query-gpu=index,memory.used,utilization.gpu --format=csv,noheader
```

公网由你处理时，保留回环后端、HTTPS反代和评审账号，具体配置见[入口说明](REVIEW_ACCESS.md)。公网启用后仍须你从外网核对。源码不包含模型、论文、数据库、.env或实际口令；不要删除服务器的这些运行资料。

## 评委可以怎样体验

1. 我的文献：导入PDF；重名/改名同字节复用原件，相似版本按提示保留或替换。
2. 文献问答：选择原生Transformer，问第六作者，再问“其中Adam的β1和β2是多少”；展开原文核对。
3. 沉浸阅读：Transformer第2页点击[13]到第11页再返回；目录定位3.2.2；切Ragas查看既有对照译文、滚动联动及导出。
4. 探索发现：展开真实保存的中文研究任务及两条来源；需要新任务时实际调用arXiv，不伪造离线检索成功。
5. 引用图谱：按[固定20篇清单](GRAPH20_CASES.json)选择构图，查看局部排名及原文，导出图谱。
6. 写作工坊：选Transformer、RAG、Ragas生成研究计划，核对摘要来源和方法图，编辑后导出；图表输入47/43/72的实测向量段数，切页再返回，导出SVG及图注。

完整口播及镜头见[七分钟脚本](DEMO_SCRIPT.md)。模型生成内容仍需核对原文，研究计划不是已完成实验。

## 独立浏览器回归复现

在隔离库启动已配置随机评审账号的四卡服务并通过回环独立端口转发。验收机另装Playwright及匹配Chromium；不需为产品加入Playwright依赖。不使用正式库或默认18474端口。创建权限600的私有JSON，字段如下（示意文本不含真实口令）：

```json
{
  "base_url": "http://127.0.0.1:18479",
  "isolatedLibrary": true,
  "username": "test-reviewer",
  "password": "替换为隔离实例随机测试密码"
}
```

```sh
node scripts/verify_browser.mjs \
  --config runtime/private-browser-config.json \
  --output runtime/browser-新的编号 \
  --fixtures /你的官方资料目录 \
  --playwright-module /独立Playwright安装目录/index.mjs \
  --executable /匹配Chromium可执行文件
```

脚本要求已有官方图谱20篇、Transformer/RAG/Ragas、中文任务与翻译缓存。它会真实生成计划、问答、下载文件及重复上传；仅隔离库可用。每轮新目录保留失败，不用旧报告覆盖；任务完成后由运行者停止隔离模型服务、关闭端口转发并保护凭据。
