# 官方 20 篇论文引用图谱验收

2026-10-28，使用组委会资料包中 20 份原生 PDF，共 816 个物理页，完成服务器入库、引用证据与局部排名核对。文件名、SHA-256、页数、参考文献物理页范围及固定引用对见 [样本清单](GRAPH20_CASES.json)，实际接口结果见 [验收记录](GRAPH20_VERIFICATION_20261028.json)。原 PDF、全文摘录、模型权重和数据库不上传仓库。

## 样本与方法

覆盖 LayerNorm、Transformer、BERT、GPT-1、GPT-3、Scaling Laws、T5、LoRA、Codex、CoT、InstructGPT、Emergent Abilities、FlashAttention、BLOOM、LLaMA、Llama 2、Mistral、Qwen2.5、DeepSeek-V3 和 DeepSeek-R1。GPT-2 来自此前另行下载的作者原件，不计入本轮官方 20 篇。

先独立限定各 PDF 的参考文献页范围，在原生提取文本中用完整题名／编号查找候选，再逐条阅读 102 个候选的书目上下文，固定为 100 个正例和 2 个混淆负例。核对期间发现 LLaMA 第 16 页及 Llama 2 第 44 页实际引用的是 Zhang 与 Sennrich 的 RMSNorm，而不是 Ba 等的 LayerNorm。修复题名起点检查后，两条后缀误连被排除。

这是一组已复核候选的回归基准，没有盲审全部 380 个可能的有向论文对，不将 100/100 候选覆盖率写成全体引用召回率或通用准确率。题名起点依赖标点，遇到不带标点的书目、OCR 错字或特殊排版仍可能漏连。

当前局部入度最高的是 Transformer（14）；PageRank 最高的是 LayerNorm（约 0.2051），两者含义不同。局部 PageRank 受到边方向、所选样本及无出边节点影响，不能解释为全球被引量、学术质量或创新性评价。

首次模型验收没有覆盖六篇摘要，来源检查拒绝了该结果。现在逐篇读取摘要、校验唯一结论和对应来源后合并，任一篇不通过则整份综述拒绝展示，生成期间仍检查文献指纹。修复后真实六篇输出通过来源与数值检查，耗时以记录为准。逐句对照摘要未发现明显数值或主语串用；其中 GPT-3 概括侧重背景局限，仍不是完整方法综述，也不是全文语义审查。

## 本轮修复

- 首页标题结合字号、上半页基线和连续行读取，保留 Llama 2 短前缀、小型大写单词及断词，避免把 LoRA 正文图中的 Pretrained 标签当题名。通过正常重解析更新这两份文献，不直接改数据库。
- References 遇到已识别的字母附录、Checklist、Attention Visualizations 等边界停止，避免将附录正文当作书目；保留作者姓名缩写和普通书目标题。
- 完整标题检查起点和结尾，拒绝更长题名的前缀／后缀误连；编号匹配规则保留。
- 图谱算法版本更新为 `references-v3`，旧指纹与旧综述需要重新生成。
- 页面实测发现密集有向图的力导向布局挤在一起；12 篇及以上改用环形布局，突出当前节点的相邻引用，选中或悬停显示题名，保留全部连边与排序列表。没有按展示需要新增或删除引用。

对 LoRA、Llama 2 首页以及两处 RMSNorm 参考文献原页做了渲染回看。Llama 2 第 25 页原有 PDF 内容跳过保护提示仍保留；页数完整不意味着复杂图表及公式全部无损还原。

## 复现

先从比赛资料包取得清单对应原件并导入本地后端，等待解析完成、确认版本。脚本不会导入、归档或修改文献，只读取当前库、构图并可选调用本地模型。

```sh
.venv/bin/python scripts/verify_graph20.py \
  --base-url http://127.0.0.1:18474 \
  --fixture-dir /path/to/科研小助手/pdf \
  --review --output docs/GRAPH20_VERIFICATION_20261028.json
.venv/bin/python -m unittest discover -s backend -p 'test_*.py'
```

后续仍需覆盖更多参考文献格式、扫描件和引用召回率，并结合新论文核验旧 Future Work 是否已被解决。真实 20 篇图谱回归不代表这些工作或全部参赛交付已完成。
