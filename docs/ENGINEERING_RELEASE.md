2026-10-30，按用户要求优先收尾工程，公网部署及平台视频发布由后续安排。本轮将现有六个模块的核心操作连起来验证，并修复实际发现的问题；“工程候选版”指下述已实现范围，不代表所有赛题扩展方向或提交材料均已完成。

## 本轮修复

- CSV与柱/折线选择在两类页面切换后保留；异步文件导入完成时即使已切页，也更新同一页面会话。真实React组件回归重现旧提交的丢失问题，并确认当前修复有效。刷新前仍需导出备份。
- 图表SVG改用已有显式xmlns的DOM内容导出，与写作模块一致。jsdom中旧序列化会产生重复xmlns；现在XML解析、特殊字符转义、数值及图注原始CSV均通过检查。这是组件环境的兼容性修复，未声称已在真实浏览器复现旧行为。
- 历史研究任务在读取时核对文献及来源指纹。缺摘要、来源变化或文献失效时，展示待生成状态并隐藏旧结论，原数据库历史保留。点击重试后复用原文与检查点，不重新检索下载。当前有效综述不能无故重试覆盖。

## 一次运行主要API回归

先在服务器对已停写的文献库创建SQLite一致性备份及原PDF副本，使用独立数据目录、独立端口启动同一四卡服务。禁止把正式库当作隔离库；文件夹路径、服务管理与模型配置参照[GPU复现](GPU_REPRODUCTION.md)。本轮数据副本不重新下载或改变任何原件；它不等于空库安装验收。

在可访问该回环入口的机器运行：

```sh
.venv/bin/python -m scripts.verify_release \
  --base-url http://127.0.0.1:18478 --isolated-library \
  --fixture-dir /你的官方资料目录 \
  --gpt2-pdf /你的作者官方GPT2原文.pdf \
  --output-dir runtime/release-check-新编号 \
  --refresh-stale-history
```

资料目录内应有pdf子目录，包含官方文件；GPT2按仓库既有官方来源准备。副本须已有对应的有效原生/扫描版、RAG、Ragas、20篇图谱样本和研究历史。脚本拒绝默认18474、非回环地址及覆盖既有报告。输出各项JSON、日志和SUMMARY.json；任一失败最终非零退出。`--refresh-stale-history`明确允许仅在副本补生成失效历史摘要，会调用本地模型；不用该参数时只核对有效完整历史。脚本不负责创建副本、启动/停止服务或释放GPU，运行者须收尾。

## 运行与打包

```sh
npm ci
npm test
npm run build
.venv/bin/python -m unittest discover -s backend -t . -q
```

`npm test`的组件用例全部使用隔离DOM和API替身，不访问正式服务或操作客户端鼠标。安装及四卡运行见[本地后端](LOCAL_BACKEND.md)；以后需要的只读HTTPS入口工具见[入口检查](PUBLIC_DEMO.md)。

在所有变更真实提交、工作区干净后执行：

```sh
python3 scripts/package_release.py
```

工程ZIP、提交编号清单及SHA-256生成在output/release，均不再提交进自身。包只含Git跟踪文件，不含模型、原论文、数据库、密钥或虚拟环境；依赖和权重仍需按说明准备。完整Git历史保留在仓库。技术PDF仍为团队信息待补的初稿；公网和公开视频按用户要求另行处理。

结束后停止本次隔离模型服务并关闭SSH转发；正式服务也按用户“不运行时释放显卡”的要求保持停止。使用时按原说明启动四卡服务，未改变为CPU模型版本。
