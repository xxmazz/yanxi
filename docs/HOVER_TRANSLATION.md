# 阅读正文悬停翻译

2026-10-30。沉浸阅读 → 原页与解析正文 → 开启悬停翻译。默认关闭，开启后在右侧正文句子停留550毫秒、点击或键盘Enter，显示本地Qwen译文与对应原句。支持中文/英文目标语言，Esc或关闭按钮收起译文。

## 实现

按句子分段，PDF单换行在分句时视为空格，之后仍从原文提取精确区间，保留换行及Unicode字符偏移。完整带标记的公式和代码不进入可悬停片段；长句最多700字符，过长时按空白切小块。数字引用按钮继续负责书目双向跳转。

POST /api/documents/{id}/translation/selection/{page} 接收start、end、text和target。服务端检查文献已解析/版本已确认/未归档，核对页面及选段逐字一致，最多800字符；返回任务和来源文献、物理页、字符区间、页面SHA-256。复用既有本地翻译队列与数值/公式保护，不改写论文、整页翻译缓存或问答索引。

每个阅读组件一次只提交一个选段任务，快速移开不提交。结果/错误按原句和目标语言最多缓存60项，仅在当前阅读会话内保存；不会因再次悬停自动重试错误，重试须点击按钮。切文献、翻页、换语言或关闭翻译都会隐藏原结果，异步旧结果不再显示。关闭浮层不撤销已提交推理；离开阅读页后短任务可继续完成，后端仍受两任务队列限制。

## 边界

当前悬停位置在解析正文，原PDF图像没有文字覆盖层。扫描页依赖OCR，缺少数学标记的公式仍可能被分句或翻译。缓存不跨刷新持久化；选段译文不视为整页翻译完成。真实样例中point-wise仍出现混合术语译法，原句及译文并排可核对；这些回归不等于一般学术语义质量评测，也没有验证541页教材整篇翻译。
