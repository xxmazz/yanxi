# 显式编号章节导航

2026-10-29，在「原页与解析正文」阅读模式增加可展开章节目录。点击条目后同步物理页，并在解析正文中高亮原始标题；不需要模型推理或新增运行依赖。

## 识别方法与边界

使用已保存正文独立行上的显式编号（1、3.2、3.2.1）建立三级路径，支持英文标题与中文标题开头，同时添加可识别的 Abstract／摘要及 References 定位项。子标题只在父编号已存在时加入；重复页眉、倒退章号、明显表格数值行、公式和句末标点的正文行被过滤。每个定位项保留原文字符区间、物理页码、页 SHA-256，复用引用导航的 Unicode 码点核对与高亮。

目录根据文本规则自动识别，可能漏识别或误识别。当前只覆盖参考文献之前的显式编号章节，未实现附录目录、跨行标题拼接、无编号标题的字号／版面推断、PDF 内嵌书签解析，也未保证教材各章完整目录。缺少父标题时不猜补层级。原始页和物理页码始终可用。

目录随 GET /api/documents/{id}/reading-links 返回 outline 列表，不修改数据库、原文、版本决策或图谱连边。指纹纳入 reading-links-v3 算法版本。
