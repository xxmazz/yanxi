这些结果表明：引用可逐字定位、数值可核对，仍不能保证作者序号、实体归属或结论语义正确。接下来需要补作者署名结构与顺序核对、硬件段落召回，以及更广泛的官方单篇／多篇问题验证。未覆盖 BLEU 对比、全部跨篇问题或完整 20 篇图谱。

本轮修复一个接口问题：多条结论使用同一证据段时，原先会重复拼接整段，或将不相邻摘录直接连接；现在展示原证据的一个连续段落。新增 API 回归同时检查两条结论、单个来源及连续引文，当前后端 73 项测试通过。提示词尝试未稳定改善问答，已撤回，公开记录保留最终部署版本的实际结果。

## 复现

```sh
# 已安装 backend/requirements.txt；在仓库根目录运行
python -m scripts.verify_official_fixtures \
  --fixture-dir /path/to/科研小助手 \
  --base-url http://192.168.3.193:18474 \
  --output runtime/regression/official-verification.json
```

首次运行会上传官方扫描件，其余原生版本只读核对。若扫描件尚待相似版本确认，可先在界面处理；增加 `--keep-scan` 会显式选择保留两者，只影响扫描件自身。脚本不自动恢复已有归档文献。五个问题有失败时，仍保存完整结果并返回非零退出码，不将失败改记为通过。脚本本身不会下载资料包。
