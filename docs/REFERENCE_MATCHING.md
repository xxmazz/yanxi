# 无编号参考文献匹配与下载

2026-10-30。探索发现 → 从参考文献批量下载 → 读取参考文献。书目有明确 arXiv / CoRR abs 编号时直接列出；其余书目可逐条匹配，或顺序匹配前5条未尝试的书目。匹配不会自动下载，核对后仍需勾选并启动批次。

## 身份核对

题名从原书目截取，保留作者、年份、物理页及原文指纹。官方 arXiv API 按题名查询最多8个候选，共享请求间隔、超时和缓存。只在完整规范化题名相等、前两位作者姓氏/给名首字母通过（et al. 核对首位）且预印本年份处于书目年份前3年至后1年时通过；同一作品的版本按基础编号合并。只有一个作品通过时，才加入可下载列表。零个或多个作品通过只展示候选及原因，不下载。

结果保存到 SQLite，刷新可恢复；书目指纹改变、跨文献复用、客户端伪造编号或查询期间原文变化均不能直接进入批次。批次保留匹配方式、核对时间、官方元数据链接和原书目证据。请求过期缓存不保存为本轮匹配。停止匹配仅停止后续条目，当前官方请求会正常结束。

## 真实验证

189项后端、20项前端回归及生产构建通过。无头 Chromium 真实连接四卡隔离服务，无 API 替身或桌面鼠标操作：

- Transformer 书目 [11] 匹配 ResNet 1512.03385v1，会议年份2016、预印本2015；[20] 匹配 Adam 1412.6980v9，书目2015、预印本2014。两篇均无原书目明确 arXiv 编号。
- [13] 1997年的 Long short-term memory 未找到通过全部条件的候选，未加入可下载列表。
- 刷新后匹配依据仍在，勾选两篇后实际下载、解析12页和15页；分别66/66、49/49段已写入本地 E5 向量。
- 390像素窄屏不溢出，浏览器 JavaScript 异常为0。正式33份原PDF、1574页及文献/段落/版本选择与备份一致。

## 范围

这是 arXiv 候选内的保守匹配，不是所有会议和期刊的全文下载器。作者年份/缩写/双栏解析等复杂格式可能无法分离题名；未收录、改题名或无法唯一核对时，仍需在探索页手动检索、核对作者原件。年份容差不证明两个版本正文完全相同。不是任意 DOI 解析，也不绕过付费访问。

新增接口 POST /api/documents/{id}/reference-resolutions 接收 fingerprint 和 reference；已验证条目沿用 reference-candidates、reference-batches 接口。
