# 有来源的研究计划与架构图

对应赛题模块六的论文框架与拓扑图脚本。本轮将写作工坊接入本地 Qwen，生成包含 Abstract、Introduction、Related Work、拟议方法、评估计划和 References 的可编辑草稿，支持 Mermaid 脚本与 SVG 架构图导出。

## 使用

1. 导入论文，完成解析与版本确认，在「写作工坊 → 论文框架」填写研究设想。
2. 选择真实文献。一次最多六篇作品，同一作品的多个版本合并；没有明确第一页摘要的作品会标出未纳入原因。示例卡片不会进入写作证据。
3. 点击「生成有来源的论文框架」。已有文献结论与拟开展的方法／评估计划分开呈现，不将计划写成已经完成的实验。
4. 切换编辑／预览并导出 Markdown。修改过的草稿会标明「用户已编辑」，不继续声称生成时的检查覆盖新增文字。草稿、来源和选择会自动保存在当前浏览器；存储失败时可导出备份。
5. 展开「引用与来源核对」查看真实书目、摘要原文、物理页码、页哈希及 PDF 原页。可重新核对来源是否仍与生成时一致，或导出 JSON 来源记录。
6. 「拟议方法架构图」依据生成时的方法步骤绘制，可导出 Mermaid `.mmd` 或独立 SVG。修改正文后须核对图中步骤是否仍一致。

重新生成失败会保留原稿，成功后可恢复上一稿。上一稿恢复仅保留本次组件会话中的一份，不是完整版本管理。切换页面或刷新后，当前稿会从浏览器恢复。

## 本地处理与引用边界

- `/api/writing/outline` 接收 idea 和明确选择的 document_ids。只读取 ready、未归档且版本已确认的原文；最多 30 个 PDF、六篇作品，复用图谱的一致快照与作品合并。
- Qwen 先基于 idea 和摘要组织结构化研究计划，再逐篇概括摘要。实测小模型同时写计划与概括多篇论文可能漏来源，因此采用专用摘要提示分篇阅读并校验后组装。研究计划结构不合法时最多重试一次，仍失败则保留已有草稿。
- 相关工作复用来源编号、原文摘录和数值检查；每篇纳入摘要都须有结论，未知引用编号、无法对应的摘录和原文未支持的数字会拒绝展示。术语提示区分「不依赖人工标注的标准答案」与「不需要参考文本」；仅当原文明确含有 without having to rely on ground truth human annotations 时，将含混的「无需／不需要参考答案」收窄为「不依赖人工标注的标准答案」，原文摘录保持不变。
- References 不由模型自由编造，而由服务端依据本次文献的官方 arXiv 来源记录或 PDF 元数据生成。缺失的作者／年份标明待核对，不补造 DOI、卷期或作者。架构图中的标签也是数据，不执行用户输入或生成代码。
- 生成前后重新检查原文及书目指纹；文献归档、重新解析或元数据变化会拒绝沿用旧结果。`/api/writing/check` 可再次核验快照，不使用 GPU。
- 手动修改的正文不自动经过模型检查；导出会附生成时间、快照与编辑状态。来源核对只说明原始文献未变化，不代表手改内容已经核验。

全部推理使用现有服务器本地 Qwen2.5-7B-Instruct，不需要新模型、云端密钥或新增依赖。任务与问答／图谱综述共享请求互斥；繁忙时返回 429，不并发挤占同一模型。翻译与索引仍使用已有模型锁。

## 架构图

拟议方法步骤被转换为固定节点标识、顺序有向边、Mermaid `flowchart TD` 脚本，以及对应的 SVG 预览。引号、HTML、方括号和反斜线在脚本标签中转义，节点 ID 不接受模型自由拼接。浏览器直接绘制同一节点数据，不执行 Mermaid、Shell、Python 或 TeX。

本轮实现 Mermaid 和 SVG，尚未生成 TikZ、Graphviz 或 Matplotlib 脚本，也没有从自由代码自动推断任意复杂架构图。

## 验证

```sh
.venv/bin/python -m unittest discover -s backend -p 'test_*.py'
.venv/bin/python scripts/verify_writing.py --base-url http://127.0.0.1:18474 --output docs/WRITING_VERIFICATION_20261027.json
```

15 项新增测试覆盖服务端书目、虚构引用／链接、原文与数值、摘要覆盖、计划结构、Mermaid 标签边界、六篇上限与版本合并、无摘要／归档隔离、官方元数据、逐篇模型流程与拒答、有界格式重试、原文限定条件、API 校验及生成期间原文变化。全部后端测试共 68 项，前端工具测试 5 项通过。

真实服务器使用 Transformer、RAG、Ragas 的四个 PDF（含一个扫描版本）合并为三篇作品，核对书目、逐字摘要来源和页哈希、计划结构、来源过期检查及架构图数据。输出与范围见 [真实验证记录](WRITING_VERIFICATION_20261027.json)。公开记录保留摘录哈希，完整原文仍在文献库。

## 剩余工作

这是基于所选摘要的研究计划辅助，不能证明创新性、实验效果或完整语义正确性；不能将生成稿作为已经完成的论文提交。尚需真实实验、全文相关工作核对、最新文献查新、学术格式润色与官方用例回归。

已有数据可视化仍支持真实两列 CSV、柱状／折线图、数据极值描述和 SVG 导出。本轮不改变该模块；多维图、统计分析及模型图注仍待后续补齐。

## 2026-10-30：图表切页保留

修复数据可视化在切到“论文框架”或主导航后卸载，导致返回时真实CSV与折线选择被默认示例覆盖的问题。CSV与图形类型改由工作台的上层状态持有；编辑、文件导入、恢复示例和导出读取同一份当前输入。导入过程中切页，读文件完成后仍更新本次页面会话的输入。

此保留范围为同一页面会话，不新增浏览器持久存储；刷新或关闭前应导出图注，图注内包含原始CSV。示例仍明确标为虚构数据。本轮通过类型检查、生产构建及现有5项前端工具测试；源码审阅核对状态生命周期，尚未完成真实浏览器点击和下载落盘验收。
