## 本轮修复

原混合检索会将 `19.18` 拆成常见数字；541 页教材中大量章节、习题和图号同时匹配，正确图注可能不在前六段中。修复前，Figure 19.18 的折扣因子和 Figure 20.3 的参数倍数问题均拒答；第 21 章作者问题可以回答。修复后，前两个问题分别引用物理第 415、420 页作答。

检索现在对用户明确给出的 Figure／Fig.／图、Table／表、Equation／Eq.／公式的多段编号补召回，优先独立行上的对应图表标题，再补混合检索结果，总预算仍是六段。只从原始问题读取编号，模型扩写出的编号不触发该规则；一般小数不触发。规则只定位文字及图注，不能理解图像、还原表格或自动解析公式结构。

安装固定版本 `fonttools==4.67.0`，补齐 pypdf 的 CFF Type1 字体解析。本书物理第 205 页公式中的部分括号原先成为控制字符，安装后该页未再出现此类控制字符；这不等于公式已恢复为 LaTeX。

逐页比对还发现 pypdf 触发图形对象遍历保护、跳过部分内容。本轮保留保护上限，将当前解析线程的警告写入 `pages.warning` 和文献 `warnings`，在文献卡片及阅读器呈现页码和核对提示；不会将其他线程文献的警告混入本页。重新解析会重新生成警告记录。

## 复现

先按 [后端说明](LOCAL_BACKEND.md) 安装更新后的依赖并重启服务，导入 Transformer、RAG 与已有的 15 页自制扫描样本。手动从作者发布页下载教材至 runtime；脚本本身不下载文件。

```sh
# 在服务所在 Linux 主机执行；base-url 应与实际监听地址一致。
# --reindex 明确要求重新索引这本书，不修改其他文献的版本决策。
.venv/bin/python scripts/verify_long_document.py \
  --base-url http://192.168.3.193:18474 \
  --pdf runtime/regression/UnderstandingDeepLearning_02_09_26_C.pdf \
  --reindex \
  --process-pid "$(systemctl --user show yanxi -p MainPID --value)" \
  --output runtime/regression/long-document-verification.json
```

在其他机器运行时省略 `--process-pid`。省略 `--reindex` 会复用已就绪的同文件，记录中的索引时间为 null，不把复用耗时冒充完整索引耗时。脚本会上传指定教材、验证现有论文，不自动下载缺失论文或确认相似版本。
