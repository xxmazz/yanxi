# AI 协作记录 · 第一开发会话

日期：2026-10-23，Asia/Shanghai。以下记录真实需求与实现过程，不构造不存在的多组 Prompt。

## 目标与选题

围绕“研析——科研文献智能助手”开发科研阅读与写作工作台，先交付可运行的交互原型，再按实际开发进度迭代功能。项目用于 AI 大模型创新应用挑战赛个人研究生组。

## 本轮实现与反馈

- 从空工程开始，先提交初始化，再实现六个导航页面和前端交互，之后提交 CSV 和写作工具。
- 首次布局截图检查后，提高文字可读性并移除在线字体依赖。
- 浏览器自动检查中修正导航定位方式；移动截图发现导航关闭动画影响快照，移除手机导航动画并重新检查。
- CSV 解析单测覆盖引号、逗号、负值、零、BOM、CRLF、无效值与行数上限。
- 所有 AI 相关演示在界面显式标注，未将模板回答声称为真实模型结果。

## 人与 AI 的贡献

用户：确认选题、命名、比赛赛道、开发目标、服务器和 GitHub 账号。
Codex：方案实现、前端代码、样式、演示数据组织、检查脚本、构建和阶段性服务器预览。

本轮尚未接入真实模型、PDF 解析、OCR 或真实文献检索。不存在已通过官方测试的声明。后续真实需求变更与 Prompt 演进继续增补记录。
