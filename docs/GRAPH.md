# 局域引用图谱与有来源综述

对应赛道模块五。本轮将引用图谱页面接入真实服务器文献库，计算局部引用指标，提供原文证据、摘要综述和 Future Work 线索。

## 使用

1. 先导入论文，等待解析与版本确认完成。
2. 打开「引用图谱」，选择需要分析的 PDF，点击「构建真实引用图谱」。每次最多 30 个 PDF。
3. 点击节点查看局部入度、出度、PageRank、同作品版本和相邻引用。展开「引用出处」可读逐字片段、查看物理页码、原页图片或原始 PDF。
4. 可隐藏未连边作品，按 PageRank／入度查看排序；选择同一研究方向的文献后生成简短综述，每条结论有摘要来源。
5. 「后续研究线索」展示正文里 Future Work 等明确表述，按已知年份排列。图谱、来源与综述可导出 JSON。

选择范围或文献库发生变化后须重新构图。后端在综述生成前后重新核对指纹，防止原文更新后沿用旧结果。

## 构图方法

- SQLite 一致快照中只加载已解析、已确认版本且未归档的文献。单次最多 30 个 PDF、2000 万字符。
- 从独立行 References／Bibliography／参考文献标题开始读取，遇到可识别的附录标题停止。没有找到标题时保留节点并提示，不从正文提及或主题相似度推断连边。
- 在该范围内匹配完整 arXiv 编号、DOI 或至少 18 个字母数字字符的完整标题。标题匹配忽略大小写、标点、空白、断行与印刷连字，检查词边界、题名起点及结尾分隔；拒绝更长题名的前缀／后缀误连。没有使用模糊标题相似度。
- 每条边保存匹配方式、匹配原串、原始 PDF 页码、字符区间、逐字摘录和页 SHA-256，可跨页追溯。箭头从引用论文指向被引论文。
- 同 arXiv 编号，或完整长标题加首位作者一致且编号不冲突，合并为作品节点。优先较新版本，再优先较少 OCR 的文本；只取该版本的出边，同一对作品只计一次，不计自引边。
- NetworkX 3.6.1（BSD-3-Clause）构建有向图，使用 SciPy 1.18.1（BSD-3-Clause）计算阻尼系数 0.85 的 PageRank，并统计入度、出度、弱连通分量与孤立节点。小图的力导向布局固定随机种子，12 篇及以上使用固定节点顺序的环形布局避免节点重叠；重复构图可复现。大图突出当前节点相邻边，悬停或选择节点显示题名，所有引用保留在图谱及导出数据中。
- 指纹包含算法版本、所选文献身份与元数据、页号、解析方式、原文哈希和官方来源记录；导出附有生成时间。

「局部基石候选」表示当前范围内非零入度最高的作品。指标仅反映已入库论文的局域网络，不能当作全球被引量、学术质量、创新性或方法继承关系。

## 本地模型综述

复用现有 Qwen2.5-7B-Instruct，无需云端模型或额外密钥。按 PageRank 优先读取最多六篇作品的第一页摘要原文，逐篇生成并校验唯一结论后合并，避免批量生成遗漏后面的来源。检查本轮摘要是否全部被引用，复用问答的来源编号、逐字摘录和数值检查；不合格结果明确返回证据不足，保留原文可查。

这是摘要级简短综述，不能代替全文综合或语义蕴含审查。没有摘要的作品不纳入模型证据。超过六篇的图谱不会声称综述覆盖全部论文。

人工复核曾发现模型将 Ragas 的「不依赖人工标注的标准答案」误写成「无需参考文本」。已补充否定条件与 reference-free evaluation 的术语约束，并重新实测。该例也说明引用存在不等于结论语义完全正确，仍需对照原文复核。

Future Work 使用正文关键词附近的原文片段；同页重叠区间合并，单作品最多三处。年份来自官方来源记录或现代 arXiv 编号的年份，未知时标明待核对。尚未实现结合最新研究自动判断旧 idea 是否已经解决。

## 接口与复现

- `POST /api/graph/build`：`{"document_ids": [...]}`，省略／空列表表示全部可用文献，返回节点、引用边、统计、证据与指纹。不可用的指定文献或范围超限返回 409。
- `POST /api/graph/review`：同一 `document_ids` 加 `fingerprint`，返回综述、引用、读取范围与证据不足标记。指纹过期返回 409，模型未就绪返回 503，问答模型忙返回 429。

依赖已固定在 `backend/requirements.txt`，服务器环境锁文件已有相同版本。现有服务器升级后重启服务即可，不迁移数据表、不修改原文、译文或向量。

```sh
.venv/bin/python -m unittest discover -s backend -p 'test_*.py'
.venv/bin/python scripts/verify_graph.py --base-url http://127.0.0.1:18474 --review --output docs/GRAPH_VERIFICATION_20261027.json
```

17 项图谱测试覆盖正文误连、标题扩展与词边界、标识符前缀误命中、断词／连字、跨页原文坐标、附录、版本合并及冲突编号、归档／待确认隔离、页数据不完整、指纹、过期综述拒绝、20 篇有向拓扑、PageRank、数值拦截、逐篇摘要范围与生成期间原文变更。

首次真实服务器验证使用 5 个 PDF，合并为 4 篇作品、2 条引用边、1 篇孤立作品：Ragas → RAG → Transformer。逐条证据的字符区间与页哈希通过核对；四篇摘要的本地模型综述通过来源检查。历史结果见 [回归数据](GRAPH_VERIFICATION_20261027.json)。当时的 20 篇测试使用构造书目文本。

2026-10-28 已补充官方 20 篇真实 PDF、816 页、100 条引用边的候选核对与独立排名复算，见 [真实 20 篇验收](GRAPH20.md)。候选正例覆盖不等于全部引用召回率。

## 后续验收

引用标题识别与附录停止规则仍是有界启发式；缺少标题、复杂双栏顺序、OCR 错字、不同题名、特殊参考文献格式可能造成漏边或误边，须以原文回看复核。当前没有自动抓取库外被引节点、引用质量筛选或用户编辑引用边。真实 20 篇候选回归已完成，下一步补充更多版式与引用召回率评估，并实现结合新论文的未来方向核验。
