# 真实论文检索与一键入库

探索页通过 arXiv 官方 Atom API 检索真实论文，替换固定样例。支持英文主题、论文标题、中文主题和现代／旧式 arXiv 编号（可指定版本）。中文常见科研术语使用本地词表约束，其余主题由本地 Qwen 转成英文关键词；页面显示实际检索词，便于发现并纠正翻译偏差。检索与下载联网访问 arXiv，模型推理继续仅使用本地权重。

## 使用流程

1. 在“探索发现”输入主题、论文名称或编号，选择主题相关、最新发布或本页与文献库最相关。
2. 查看作者、分类、发布日期、摘要和 arXiv 原始页面。作者摘要／备注中的 GitHub 链接会单独展示，未对外部代码的质量、许可或可复现性做保证。
3. 点击“下载并加入文献库”。后台重新查询该编号的官方元数据，下载 PDF，记录来源并接入已有逐页解析、OCR 与版本检查。
4. 导入记录显示下载进度及文献状态。已解析可直接阅读和问答，相似版本去文献库确认，失败可重新导入。原始来源保存在阅读页“论文检索来源”中。

下载完成与解析完成是两个独立状态。服务重启时，中断的下载明确标记失败供重试；已进入解析队列的任务沿用原有恢复逻辑。重复导入同一 arXiv 版本复用已有文献；已归档文献不会因导入而自动恢复。

## 检索与推荐边界

每页返回最多 8 篇，支持前后翻页，最多展示前 1000 条。官方 API 请求共享至少 3.1 秒间隔；成功查询在 SQLite 缓存 6 小时。上游失败时可显示明确标记的旧缓存和获取时间；导入前的版本核对不接受过期缓存。

“与文献库最相关”先使用 arXiv 官方相关性召回当前页，再用本地 E5 比较候选标题／摘要与库中最近最多 40 篇已解析论文。页面展示最相近的已导入论文及余弦值；该排序仅针对本页，不能视为全站最相关或论文质量评分。尚未实现定期追踪、跨来源搜索、点赞反馈学习或自动评价引用质量。

本轮实测发现小模型会把“检索增强生成”误译为强化学习，已加入常见术语词表约束及回归测试；其他主题仍需用户核对检索词，英文输入可跳过转换。

## 接口与环境

- `GET /api/discovery/search?q=...&start=0&sort=relevance`：检索。`sort` 可选 `relevance`、`newest`、`library`。
- `POST /api/discovery/import`：JSON 请求体 `{"arxiv_id":"2005.11401v4"}`，返回后台任务。
- `GET /api/discovery/jobs`：最近 12 条下载任务和关联文献 ID。
- `GET /api/documents/{id}/sources`：官方标题、作者、摘要、链接、日期及导入记录。

无需新 API 密钥和额外 Python 依赖；复用 httpx 与标准库 XML 解析。服务器须可通过 HTTPS 访问 `export.arxiv.org` 和 `arxiv.org`。官方接口超时／限流会返回可读错误，不用固定论文列表替代失败查询。

下载入口只接收合法 arXiv 编号，不接受任意 URL；元数据中的下载链接不直接使用。PDF 跳转仅允许官方 HTTPS 域名，文件最大 100 MB，流式检查文件头、大小及总耗时，下载队列上限 2，复用解析队列上限 8。成功导入会保留官方元数据及 PDF SHA256。

真实服务完成中文“检索增强生成”搜索、本页 E5 排序、RAG 原论文 `2005.11401v4` 的 19 页下载与索引、重复导入复用、原 PDF 哈希及引用页核验。本地模型正确回答非参数记忆使用维基百科，并定位到第 2 页。网页另实测一键导入 `2309.15217v2`（Ragas，8 页）并打开阅读和来源记录。检查脚本为 `scripts/verify_discovery.py`，真实结果见 [验证数据](DISCOVERY_VERIFICATION_20261027.json)。
