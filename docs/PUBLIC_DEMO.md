# HTTPS入口只读检查工具

当前按用户要求先推进工程，不启用或更改公网部署。本工具供之后指定实际HTTPS入口时验收，不会自动配置域名、启动模型或发布服务。

## 用法

在已安装后端基础依赖的环境中，从实际外网机器执行；选择一份已就绪且有效的原生PDF，建议Transformer，需包含可识别的书目、正文引用和编号目录：

```sh
.venv/bin/python scripts/verify_public_demo.py \
  --base-url https://实际评审域名 \
  --document-id 原始PDF的64位小写SHA256 \
  --page 1 \
  --output runtime/public-demo/REPORT.json
```

按提示输入现有评审账号和密码，密码不回显。不提供命令行密码参数，不读取`.env`。自动化运行可由私有环境注入`YANXI_VERIFY_USER`与`YANXI_VERIFY_PASSWORD`，不要把明文写进命令、公开文件或日志；非交互且缺任一项会直接失败。运行前自行确认域名属于预期服务，已有账号仅发送给显式指定的同源HTTPS地址。

## 检查范围

- 系统证书及主机名校验始终开启，不提供跳过验证的选项，不跟随重定向；只允许同源GET/HEAD，不上传或修改文献库。
- 匿名首页、API、选定PDF、原页、导航及前端资源被401和Basic认证保护；授权首页与JS/CSS资源可读取。
- health三类本地模型均ready，选定文献为ready、有效且未归档；这一步不执行推理，也不证明四卡映射或模型回答质量。
- 原件HEAD长度、Range/206及完整SHA-256对应给定文献；原页返回PNG响应和文件头。原页GET可能生成预览缓存，不改变业务记录。
- 只读导航抽查一处正文引用、一条书目和一个目录区间，核对当前页面Unicode码点位置及页哈希；报告仅保留哈希和坐标，不保存原文、密码、认证头或响应正文。

成功返回0，失败返回1；运行中途失败的报告保留已完成检查及错误类型。配置在建立检查对象前就不合法时不会创建报告。脚本有单资源大小及下载时间限制。入口只做HTTPS源格式及显式本地IP过滤，不用DNS证明公网可达。报告的`independent_external_network_verified`始终为false，因为脚本无法证明运行机器确实来自独立外网；实际网络、浏览器登录/点击、下载落盘、模型问答、长期可用性均需分别验收。

工具本身的13项隔离回归使用HTTPX模拟传输，验证只读约束、认证目的地、错误脱敏、字节哈希及Unicode来源检查；它们不是实际公网、TLS握手或浏览器验收：

```sh
.venv/bin/python -m unittest backend.test_public_demo -v
```

共享账号配置与以后部署的入口边界见[访问控制说明](REVIEW_ACCESS.md)。本轮没有修改生产`.env`、反代、账号、GPU服务或文献数据。
