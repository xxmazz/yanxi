# 有界研究任务编排

2026-10-29，在探索发现页增加「研究任务」。输入主题和 1—3 篇论文的数量后，系统按固定步骤自动检索 arXiv、保存候选、逐篇入库、等待解析与版本确认，再汇总来源。页面显示过程、状态、原论文链接、阅读入口及本地模型综述状态。

## 流程与状态

- 检索复用现有官方 API 和缓存策略；中文主题复用本地 Qwen 转换。过期缓存不可直接作为自动入库的依据。
- 在首批最多八个候选中，按官方相关性顺序选取用户限定数量；同 base arXiv 编号只选一次，跳过已归档记录。页面明确说明选择依据，不声称语义质量筛选或引用含金量评估。
- 下载与索引复用现有有界队列。下载记录完成后仍须检查正文解析状态，只有 ready 且有效的文献才进入来源汇总。
- 相似版本需要确认时暂停为 needs_review，用户在文献库处理后可从检查点继续；不擅自覆盖版本。
- 记录原始查询、选定编号、下载任务编号、入库身份、过程与结果到 SQLite research_tasks 新表。不修改已有文献表结构；升级前已备份数据库。
- 失败、中断或待确认可重试，复用已保存候选、已有下载任务和已入库文献。解析失败需先在文献库重新解析。服务重启将活动研究任务标为 interrupted，等用户继续，不隐式重新启动下载或推理。
- 取消只停止后续任务步骤，已提交的单篇下载／解析正常结束，文件保留。每次最多一个活动研究任务、最多三篇论文，每次运行等待上限20分钟。
- 本地模型已加载时调用已有图谱摘要综述及来源检查；未加载时，完成来源汇总并明确显示模型综述不可用。完成状态只表示有界任务结束，不代表全文研究或所有结论已验证。汇总结束前重新核对文献有效状态。

这是基于现有工具的固定有界任务编排，尚未实现模型自主选择任意工具、动态重规划、多 Agent 协同或跨任务偏好学习。没有新增模型、云端 API 或运行依赖；任务保存与恢复不等于完整对话记忆。

## 真实验证

使用仅监听回环地址的临时 CPU 服务，正式 GPU 模型保持停止。

1. 查询 2005.11401v4，自动复用已入库 RAG 论文19页，解析状态检查后汇总来源。
2. 浏览器输入1905.07830v1，实际官方返回题名为 HellaSwag: Can a Machine Really Finish Your Sentence?。自动下载新文件、完成14页解析和BM25索引、保存官方来源并汇总。该编号不是RMSNorm，展示以官方返回题名为准。
3. 两条任务的结果 document_id 与服务器原 PDF SHA-256 一致，官方来源表包含实际 arXiv 编号；任务历史跨服务重启保留。
4. 页面清楚显示未加载本地模型，没有生成摘要综述。本轮没有使用 GPU，未验证中文主题或多篇新下载＋模型综述的 GPU 端到端流程。

121项后端测试、5项前端工具测试及生产构建通过。新增9项任务测试覆盖成功持久化、单活动任务、失败重试不重复检索／导入、版本确认后继续、取消、过期缓存拒绝、重启中断、超时、归档与汇总期间状态变化、候选去重及API验证。

公开验收记录见 [真实任务记录](RESEARCH_TASKS_VERIFICATION_20261029.json)，不分发论文原文。复现只读核对：

```sh
.venv/bin/python scripts/verify_research_tasks.py \
  --base-url http://127.0.0.1:18474 \
  --output docs/RESEARCH_TASKS_VERIFICATION_20261029.json
```

此脚本要求上述真实任务已通过UI或API执行完成，脚本本身不下载论文或启动模型。

## 接口

- POST /api/research/tasks：query（2—240字符）、limit（1—3），返回202及任务身份。
- GET /api/research/tasks：最近20条任务。
- GET /api/research/tasks/{id}：单任务详情。
- POST /api/research/tasks/{id}/retry：从检查点继续；运行中或完成态不能重试。
- POST /api/research/tasks/{id}/cancel：取消后续步骤。

正式服务目前仍停止，以保留GPU资源；代码与前端构建已同步服务器，下次启动即可使用。本轮CPU新索引不含E5向量，当前用BM25检索；需要向量检索时须在模型启动后重新解析这份新文献。
