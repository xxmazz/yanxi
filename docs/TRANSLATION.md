# 本地论文对照翻译

对应保存的赛道原文第三模块“中英对比与联动滚动”和第六模块“学术翻译”。进入已完成解析及版本确认的服务器论文，选择“中英对照翻译”。

## 使用方式

- “翻译本页”：按物理页码翻译当前页，中文与学术英文可选。
- “翻译整篇”：后台逐页翻译，显示总段落和已完成数；任务在切换页面后继续。
- 两侧正文按相同段落编号对应，从任意侧滚动会同步另一侧的段落位置；可取消勾选联动。
- 在原文侧鼠标选中文本，展开“局部翻译 / 中文摘要译为学术英文”，点击“带入选中文本”；也可直接粘贴最多 2400 字的中文摘要或英文段落。
- 整篇完成后导出包含原文、译文、物理页码及段落编号的 Markdown。
- 取消在当前推理段完成后生效，已校验段落仍保留。错误或重启中断后重新发起，可复用已完成的段落。

## 实现与可复现性

翻译只调用已有本地 Qwen2.5-7B-Instruct，没有云端翻译 API 或新增模型下载。原始 PDF、页面正文与问答索引不修改。

页面正文先在完整的 Markdown 代码围栏、行内代码、LaTeX 数学标记、数字型文内引用、arXiv 标识行和 URL 之外切分，默认约 900 字符一段。源段落逐字拼接必须等于保存的页面文本；文本层缺少段落标记时按长度切分，不声称已还原原生排版段落。模型只收到单段上下文。已识别的公式标记、代码和网址通过占位符保护，返回后验证出现次数再恢复；其余阿拉伯数字按数值字符串及次数校验，包含小数与百分比。对唯一匹配的 0—99 中文整数写法（如“三”）恢复原文的阿拉伯数字“3”；存在歧义时不转换。校验失败时将受保护的公式、代码、链接、引用和数字拆成原样片段，仅重译其间正文；截断在作者引用中途的尾部与独立短标识符原样保留，避免模型续写姓名或年份；无可拆片段时缩短上下文重译。仍失败则明确中断并保留已通过的段落。达到生成长度上限的译文不保存。

SQLite `translations` 表以文献、物理页、目标语言、原文 SHA-256、翻译配置版本与模型目录名标识缓存；`translation_jobs` 保存状态和进度。原文重解析变更后旧缓存不会误用于新正文。替换同名模型目录内的权重或修改翻译策略后，应升级 `backend/translation.py` 的 VERSION，使旧缓存失效。

摘要前含机构或邮箱的论文题名／署名信息原样保留。包含多条年份与期刊／会议标记的正式参考文献段保留英文书目信息，不改译作者、刊名与引用数据。

单个翻译工作线程，最多 2 个排队或运行任务。已完成的文档缓存可直接复用，不占 GPU 队列。本地问答、检索词转换与翻译共用同一模型推理锁；长篇翻译会增加其他模型请求的等待时间。服务退出请求取消，重启后将未完成任务标为中断，避免永久显示运行中。

接口：

| 方法与路径                                                | 用途                                                        |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| POST `/api/documents/{id}/translation`                    | `{target: "zh"或"en", page?: 物理页码}`，不指定 page 为整篇 |
| GET `/api/documents/{id}/translation/pages/{n}?target=zh` | 当前正文与译文，含完成标志和原文哈希                        |
| GET `/api/documents/{id}/translation/jobs`                | 最近任务，重新进入阅读可继续查看进度                        |
| POST `/api/translation/text`                              | `{text, target}` 局部翻译与摘要英译                         |
| GET `/api/translation/jobs/{id}`                          | 任务进度与局部译文                                          |
| POST `/api/translation/jobs/{id}/cancel`                  | 请求取消任务                                                |
| GET `/api/documents/{id}/translation/export?target=zh`    | 全页完成后导出对照 Markdown；未完成返回 409                 |

## 验证与边界

自动化行为测试覆盖：公式／代码／数字保留、长代码块不拆散、原文字节级对齐、缓存复用、正文变更失效、失败后续译、取消和队列容量、重启恢复、归档及待确认版本拒绝、接口参数和导出限制。

真实 GPU 回归脚本：

```sh
python scripts/verify_translation.py --base-url http://127.0.0.1:18474 \
  --document-id 文献哈希 --page 2
# 加 --whole 验证整篇及最终 Markdown 导出
```

这些校验保护可检测的格式和数值，不能证明语义翻译完全正确。没有 LaTeX／代码标记的 PDF 公式、图内标签与表格文本可能仍被模型误解；扫描页 OCR 的识别错误同样会影响翻译。原页入口用于核对。目前导出 Markdown，不提供原位 PDF 翻译；PDF.js 文内定位、参考文献双向跳转和鼠标悬停翻译仍需后续实现。整篇机制可分页处理已入库长书，但尚未完成官方 541 页教材的全量翻译回归。
