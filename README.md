# 研析 · 科研文献智能助手

传智杯 AI 大模型创新应用挑战赛项目。当前阶段：前端交互 Demo。

## 运行

Node.js 22.12+，或兼容的较新版本。

```sh
npm ci
npm run dev
```

打开 http://localhost:4173。生产构建：npm run build。

## 开发过程

从项目初始化开始保留真实本地 Git 提交；仓库地址与访问方式确定后按真实开发批次推送。不能通过改写时间或拆分已完成代码来伪造开发过程。

本阶段展示的数据、检索结果、Agent 状态和回答均为演示；不声称已经接入真实模型或通过官方测试。

## 当前可以体验

- 文献库：搜索、筛选、星标、排序、卡片/列表切换、目录 JSON 导出。
- 文献对比：多选后的元数据并排查看。
- PDF：本机 PDF 导入与原文件预览；元数据持久化，文件内容不持久化、不上传。
- 阅读与问答：Transformer 固定阅读样例、预置问答与来源入口；未覆盖的问题明确告知尚未接入模型。
- 研究图谱：手工整理的示例关系，可选中、筛选、键盘操作、JSON 导出；未执行 PageRank 或引用抽取。
- 写作：确定性框架模板、编辑和 Markdown 导出。
- 图表：两列 CSV 文件/文本、柱状/折线图、SVG 导出、基于数值的图注描述；初始数据是虚构演示。
- 响应式桌面和手机布局。
