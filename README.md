# 研析 · 科研文献智能助手

面向科研阅读与写作场景的文献工作台，传智杯 AI 大模型创新应用挑战赛参赛项目。当前版本提供可运行的前端交互原型。

## 功能概览

- 文献管理：关键词搜索、筛选、星标、排序、卡片与列表切换，以及目录 JSON 导出。
- 文献对比：多篇文献元数据并排查看。
- PDF 阅读：校验 PDF 文件头，导入本机 PDF 并预览原文件；本机指纹识别内容完全相同的重复文件，浏览器保存文献元数据。
- 阅读问答：固定论文阅读示例、双语切换、预置问题回答与来源入口。
- 研究图谱：示例关系的选择、筛选、键盘操作与 JSON 导出。
- 写作工具：论文框架模板编辑与 Markdown 导出。
- 数据图表：两列 CSV 导入、数值校验、柱状与折线图、SVG 和图注导出。
- 自适应布局：桌面与移动端导航、弹窗和内容排版。

## 运行方式

环境：Node.js 22.18+ 或 Node.js 24。

```sh
npm ci
npm run dev
```

浏览器访问 `http://localhost:4173`。

```sh
npm run build
npm test
npm run preview
```

## 演示范围与数据

此版本聚焦文献工作台的交互流程。问答采用预置示例，研究关系使用人工整理的示例数据，写作采用可编辑模板；图表初始数值为演示数据。重复检测只比较本机计算的文件内容指纹，可识别字节完全相同但文件名不同的 PDF，不代表语义去重或论文版本差异分析。当前版本不提供模型推理、OCR、PDF 正文解析或在线文献检索服务。

本地 PDF 原文件仅在当前浏览器预览，不上传服务器。刷新后需重新选择 PDF 文件；目录与星标保存在浏览器本地。服务密钥应由后端管理，不得写入前端变量。
